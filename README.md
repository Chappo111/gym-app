# Тренировки — мини-приложение для Telegram

Бесплатно и без своего сервера: приложение лежит на GitHub Pages, данные каждого пользователя
хранятся в его облаке Telegram (CloudStorage) и доступны с любого устройства.

## Что внутри

- **📚 Упражнения** — 96 упражнений. Детальная схема человека спереди и сзади: нажми на мышцу —
  покажет упражнения для неё (основная и вспомогательная нагрузка); повторное нажатие выбирает соседнюю
  мышцу (например, передние → средние дельты). Поиск, фильтры по группам и инвентарю, ★ избранное.
  В карточке — подсвеченные мышцы, техника по шагам, частые ошибки, рекорд и похожие упражнения.
- **🏗 Тренировка (конструктор)** — подходы, повторы, порядок, кнопка ⇄ «заменить на похожее».
  Живая **оценка 0–100** с разбором и **тепловая карта мышц** (чем больше подходов — тем краснее).
- **✨ Собрать за меня** — генератор: что тренируем, цель (масса/сила/рельеф), уровень, инвентарь
  (весь зал / только гантели / тренажёры) и время. Подбирает упражнения, подходы и порядок и выбирает
  лучший вариант по оценщику.
- **📋 Программы** — свои сохранённые тренировки и 7 готовых программ.
- **▶ Режим тренировки** — вес и повторы кнопками ±, «прошлый раз», рекорд, подсказка разминочных
  подходов, таймер отдыха с кольцом, звуком и вибрацией, конфетти за новый рекорд, прогресс по упражнениям.
- **📈 Прогресс** — статистика, недели подряд, календарь активности за 12 недель, карта мышц за неделю
  (и какие группы пропущены), рекорды с графиком, история с повтором и удалением тренировок.
- Тёмная и светлая тема подстраиваются под Telegram, плавные анимации.

## Публикация — 10 минут, бесплатно

### 1. Выложить на GitHub Pages

1. Зарегистрируйся на [github.com](https://github.com) (если ещё нет аккаунта).
2. Справа вверху **+ → New repository**. Имя, например, `gym-app`, тип **Public** → **Create repository**.
3. На странице репозитория: **uploading an existing file** (или **Add file → Upload files**),
   перетащи все файлы из таблицы выше → **Commit changes**.
4. **Settings → Pages**. В «Build and deployment» выбери **Source: Deploy from a branch**,
   ветка **main**, папка **/ (root)** → **Save**.
5. Через 1–2 минуты появится адрес вида `https://ТВОЙ_ЛОГИН.github.io/gym-app/` — открой его в браузере
   и проверь, что приложение работает.

### 2. Подключить к боту в @BotFather

1. В Telegram открой [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя и username бота.
2. `/mybots` → выбери бота → **Bot Settings → Menu Button** → отправь адрес с GitHub Pages,
   затем название кнопки, например `Тренировки`.
3. По желанию: там же **Bot Settings → Configure Mini App → Enable Mini App** и тот же адрес —
   тогда в профиле бота появится кнопка «Открыть», а приложение можно будет открыть ссылкой
   `https://t.me/username_бота?startapp`.
4. По желанию: `/setdescription` — текст, который человек видит перед «Старт», например:
   «Нажми кнопку „Тренировки“ слева от поля ввода 👇».

Готово: открой чат с ботом и нажми кнопку **Тренировки** слева от поля ввода.

> Бот без сервера не отвечает на сообщения — это нормально, всё происходит в приложении.
> Токен бота нигде вводить не нужно.

## Как обновлять

Измени файл на GitHub (кнопка ✏️ в просмотре файла) или загрузи новую версию — через минуту
обновится сайт. Telegram любит кэшировать: после изменений увеличь номер `?v=14` в `index.html`
(во всех местах, например на `?v=15`).

## Как добавить упражнение

В `data.js` скопируй любую строку из списка `exercises` и поменяй поля — описание полей в начале файла.
Оценщик и карта мышц подхватят его автоматически. Программы — там же, в `programs`.

## Где хранятся данные

- **В Telegram** — в CloudStorage: у каждого пользователя своё облако для этого бота, до ~4 МБ —
  это годы тренировок. Данные привязаны к боту: если сменить бота, история не перенесётся.
- **Если открыть адрес в обычном браузере** — данные сохраняются только в этом браузере
  (удобно для проверки, внизу вкладки «Прогресс» это написано).

## Проверка на компьютере

```bash
cd gym_bot
python3 -m http.server 8000
```

Открой http://localhost:8000. Без Telegram всё работает так же, только без вибрации и облака.

## Ограничения

- Таймер отдыха срабатывает, пока приложение открыто: присылать сообщения в чат может только бот
  со своим сервером.
- Человек на картинке схематичный (не анатомический атлас), но все 19 групп мышц на своих местах.
